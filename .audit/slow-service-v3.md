## Semantics and gates

Nearest rank is `ceil(debits * percentile / 100)` over negative-leg magnitudes
in the selected account, interval and accepted checkpoint. Credits are excluded.
Equal timestamps and equal amounts still count with multiplicity. No debits
means `0` and `null`. Accounting solvency continues to combine timestamp cohorts.
Rejected amendments change neither balance nor distribution history.

Provisional bounds are 24,000 active journals, 72,000 accepted leg edits and a
640 MiB guest heap. Measured sizes are 6,000 and 24,000 journals with 1,024
operations. Existing broad tiers remain provisional until parent calibration.
No clock tightening can substitute for the fresh blind difficulty gate.

The approved benchmark defaults to base 6000, with `--max-history` reaching
72,000 accepted leg edits. `--negative-heavy` requires base 6000 and max-history,
then uses 2,000/8,000 journals with seven negative legs and one positive leg,
reaching 63,000 accepted debit edits. Those are local memory diagnostics, not
the official 6,000/24,000 phase sizes. The six-file bundle is now synchronized,
including the separately approved capacity-gate README update.

Maximum-history capacity also gates all 40 efficiency points. It adds no
correctness groups or points. Wrong output, time or memory failure retains
earned correctness points under the same published execution limits. The
parent owns the seeded capacity traces and calibration.

Private single-child admission, capped grading, reference layouts, calibration,
trusted host capacity and fresh blind trials belong to the parent. This task
does not add public storage, locks or private admission logic. Infrastructure
503 responses still release reservations without consuming an attempt.

The 12 announcement files belong to the email worker and stay untouched.
The catalog stays closed. No commits, branch changes, push, deployment,
production migration or email is authorized. Any first submission scoring 100
rejects the launch. Preserve failed v1/v2 trial artifacts without opening them.
